# Проверка универсальности MMP

## Что подтверждено

| Конфигурация | Наблюдаемое доказательство |
| --- | --- |
| Линейная цепочка | Отдельные вызовы метрик и финализации. Второй начался после завершения первого. |
| Параллельное разветвление | Проверены перекрывающиеся интервалы двух корневых вызовов и двух вложенных вызовов внутри распределителя. |
| Ветвление по AI | Контрольный адаптер прошёл оба маршрута. Живой OpenAI tool call выбрал распределитель и углублённый маршрут. |
| Ветвление по правилу | Две длины задачи выбирают проверки или метрики в режиме без AI. |
| Объединение | Отдельный MCP-модуль получил обе ветви и вернул их наблюдения. |
| Ожидание человека | Все предыдущие MCP-вызовы завершены. Ввод и вариант принимаются из формы. Сервер создаёт новый корневой MMP-вызов. |
| Ограниченный повтор | Harness запускает до трёх последовательных корневых вызовов, проверяя прогресс. Реальный вложенный цикл возвращает `CYCLE_DETECTED`. |
| Одновременные запуски | Два сценария проходят в разных браузерных контекстах. Проверены разные данные и correlation ID, отказ при чтении чужого запуска и отмена. |

Перекомпоновка меняет порядок двух совместимых операций, включает отдельный Python-декоратор, заменяет TypeScript-метрики Python-метриками, заменяет модель анализа детерминированным модулем и подменяет ресурс формы вместе с объединителем. Композиция без AI опускает нормализацию и использует общую финализацию в другом графе. Все вызовы проходят stdio или Gateway. Сторонний пакет имеет собственный `pyproject.toml`, lockfile и окружение. Его реализация использует официальный Python MCP SDK и публичные данные контракта.

## Живой AI

Тест `verify:universality:live` выполнялся отдельным процессом с ключом из окружения. `openai/gpt-4.1-mini` вернул tool call для `dispatch`; `google/gemini-2.5-flash` был вызван внутри модуля анализа и внутри модуля, выбранного человеком. В одном из промежуточных прогонов стадия модели завершилась ошибкой при меньшем токенном лимите. Повтор с увеличенным лимитом вернул два ответа Gemini через реальные MMP-вызовы.

## Стандарт и Harness

Изменений в ядре MMP, публичных схемах и нормативной спецификации нет. Достаточны точные контракты, публичные механизмы admission и routing, стандартные MCP resources и существующая граница Gateway. Harness принимает решения о графе, ограничивает повторы, хранит состояние, вызывает модель, показывает историю и проверяет ввод человека. Форма получена из MCP-ресурса, а локальный мост передаёт только параметры продолжения.

MMP пригоден как основа взаимозаменяемых модулей, когда стороны согласовали семантику контрактов и доверенные операции. Проверка охватывает выбранные сценарии и не утверждает автоматическую совместимость произвольных контрактов, полноформатный MCP Apps Host, восстановление после перезапуска или изоляцию недоверенного кода на уровне ОС.

## Фактические прогоны

- `npm run verify:universality` — 14 прошли, 0 ошибок, 0 пропусков. Из них 6 тестов Playwright в Chromium и 8 проверок Harness и real MCP. Отдельно проверены мобильная ширина 360 px и продолжение с клавиатуры.
- `npm run verify:release` — 23 существующих теста прошли. Сборка, линтеры, архитектурные проверки и проверка типов прошли.
- `npm run check` из `spike/` — 7 прошли, 0 ошибок, 0 пропусков.
- `uv build` для независимого пакета создал wheel и исходный архив. Новый CI job проверен через `actionlint`.
- Итоговый живой прогон вернул tool call `dispatch` от `openai/gpt-4.1-mini` и два результата `google/gemini-2.5-flash` от разных этапов.

Независимая проверка GPT-6 Luna охватила границы архитектуры, sandbox, отмену, происхождение модельных ответов и разделение трасс. Разработка отдельного Python-пакета и исходного набора браузерных тестов велась независимо. По замечаниям явный model tool call сохранён в состоянии, исход отменённого вызова фиксируется отдельно, а пересечение трасс проверяется автоматическим тестом.
