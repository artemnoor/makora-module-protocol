# Independent release experiment

Run `npm run verify:external` from the MMP checkout. The driver creates a fresh directory under the system temp directory, builds and installs the local SDK tarball there and creates an independent Python environment from the Python provider lockfile. It copies the two independently authored providers and an existing Python server as an unmodified interoperability peer. The external process imports only the installed SDK and Reference Host plus its own harness.

The JSON graphs cover a linear chain, parallel computation and merge, a conditional transition, a user checkpoint and an optional inference step. The same measurement modules are reused. The harness also checks nested Node → Python annotation, a Python replacement for the Node classifier, an explicit adapter into the existing research module and both independent starter modules. The controlled inference fixture runs once in the opted-in graph and zero times in the fully deterministic graphs.

The JSON vocabulary is a local fixture for this experiment. The driver performs no package publication or remote repository changes. See the [developer guide](../../docs/developer-guide.md) for the public interfaces and the [release report](../../docs/release-0.1.0.md) for test scope.
