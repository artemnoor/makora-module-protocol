# Independent release experiment

Run `npm run verify:external` from the MMP checkout. The driver creates a fresh directory under the system temp directory, builds and installs the local SDK tarball there and creates an independent Python environment from the Python provider lockfile. It copies the two independently authored providers and an existing Python server as an unmodified interoperability peer. The external process imports only the installed SDK and Reference Host plus its own harness.

`npm run verify:external:hosts` runs the same JSON graphs, modules and assertions through both public Host implementations. It copies `python-host/` into the isolated workspace, installs it with `uv sync --locked`, and starts each Host through the shared adapter in `conformance/host-adapters/`. A missing Python Host is a failure, never a skip. The TypeScript-only trace diagnostic remains extra evidence; the common assertions use module results observed through the public Host API.

The JSON graphs cover a linear chain, parallel computation and merge, a conditional transition, a user checkpoint and an optional inference step. The same measurement modules are reused. The harness also checks nested Node → Python annotation, an inverse nested Python planner → TypeScript reviewer, a Python replacement for the Node classifier, an explicit adapter into the existing research module and both independent starter modules. Provider replacement is proven by a distinct observable marker rather than a private trace. The controlled inference fixture runs once per opted-in Host and zero times in the fully deterministic graphs.

The JSON vocabulary is a local fixture for this experiment. The driver performs no package publication or remote repository changes. See the [developer guide](../../docs/developer-guide.md) for the public interfaces and the [release report](../../docs/release-0.1.0.md) for test scope.
